เปิดต่อได้ทันที: ใน BENTO IDE กด Open Project (เปิดโปรเจกต์) แล้วเลือกไฟล์ .zip นี้ ไม่ต้องแตกไฟล์
A BENTO project: the program main.py, the pictures it uses and its background photos (.jpg), in the assets folder; the .png files open in any image editor.
To continue: in BENTO IDE press Open Project and choose this .zip. There is no need to unzip it.
